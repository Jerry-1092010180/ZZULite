# 数据与隐私说明（开发阶段）

本说明依据 2026-11-03 的本地实现，供代码审阅使用；不是已完成微信平台审核的隐私声明，后续随实现更新。

## 登录与请求

账号、密码经学校公钥 RSA 加密后，通过 HTTPS 直接发送至学校统一认证服务。RSA 加密不替代 HTTPS。学校密码不保存到本机磁盘，不上传到项目自建服务器。

学校要求验证时，由使用者本人输入短信验证码完成认证。登录令牌用于查询学校数据；有效会话通过微信加密存储保持，不支持加密存储时不降级为明文持久化。会话到期、被学校拒绝或用户退出后清理。

## 本机数据

- 课表及离线快照保存在本机，以便弱网或离线查看。
- 随机设备标识用于学校登录流程。
- 宿舍电表选择、查询时间和有限的最近电量读数保存在本机，不代表云端连续历史。
- 成绩只在页面内存展示，页面隐藏时清理，不持久化成绩。
- 退出操作清理登录态、课表与电量缓存；请以随后发布的源码和实际页面为准。

本小程序不自动读取个人树莓派的数据库，不向 ESP32 发送凭据，也不包含私人采集系统的账号、电表配置或历史记录。

## 数据边界

界面应区分缓存时间、查询失败与最新结果；旧缓存不代表学校当前状态。电表返回的是剩余电量，不是实时功率；充值和数据修正不能直接视为用电。

请勿在公开 Issue、截图、日志或代码中包含学校密码、验证码、令牌、完整个人课表/成绩、个人房间编号或其他敏感信息。学校负责处理发送至其服务的请求；微信平台自身的数据处理不由本项目控制。
