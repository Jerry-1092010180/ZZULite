# 公开演示与提审说明

2026-11-04 增加常驻公开演示，所有用户在首页、登录页、更多页都能进入。页面路径：`pages/demo/demo`。没有审核账号、隐藏密码、审核专用判断或审核后移除计划。

## 功能与边界

- 用固定虚构数据展示课表周次切换、成绩学期筛选与搜索、校园卡余额刷新交互、照明／空调表切换与示例记录、教室占用状态。
- 页面始终标注虚构数据；课表周次切换仅演示交互，不声称不同周次记录来自学校。
- 不调用学校接口，不读写账号、令牌、真实课表、电表配置或任何本机缓存。
- 退出回到真实首页；去学校登录不会自动退出或清除原会话，仍须由使用者自行完成真实登录。
- 演示不支持充值、下单、付款。真实功能仍需要学校账号，学校可能要求短信验证。

## 填写审核信息

无需为演示虚构一个登录账号或提供个人学校密码。在测试备注中如实写明公开演示路径及真实登录限制；选择项应依照平台对登录要求的实际解释填写，不能把演示的免登录描述成全部真实功能都免登录。若平台仍要求可用的学校专用测试账号，需要取得相应授权或联系平台确认，不保证演示即可替代真实功能审核。
