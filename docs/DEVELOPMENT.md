# 开发与运行

本文对应当前开发中的源码快照。导入前需准备自己的微信小程序开发账号与 AppID；仓库不附带可直接上线的账号配置。

## 环境与目录

使用微信开发者工具。项目为原生小程序，TypeScript 由开发者工具编译，目前不要求构建 npm 包，不启用微信云开发。

当前主要目录：

```text
miniprogram/
  app.ts / app.json / app.wxss
  pages/       # 今天、课表、成绩、校园、电量、登录、更多等
  services/    # 认证、会话、学校接口、缓存与数据解析
  vendor/      # 第三方实现及许可证
  utils/
tests/run.cjs  # 模拟 wx API 的检查
typings/
project.config.json
tsconfig.json
```

## 导入与配置

1. 获取后续发布的源码，导入包含 `project.config.json` 的目录。
2. 使用自己的小程序 AppID；不要复用维护者的 AppID 或私有配置文件。
3. 在自己小程序的后台配置代码所需的 request 合法域名：
   - `https://cas.s.zzu.edu.cn`：统一认证。
   - `https://jwxt.zzu.edu.cn`：本科教务、课表、成绩与教室查询。
   - `https://info.s.zzu.edu.cn`：校园卡信息。
   - `https://ecard.v.zzu.edu.cn`：一卡通认证及宿舍电表接口。
4. 保持合法域名校验开启。后台修改域名后，重新打开开发项目使配置更新。
5. 先在开发工具测试，再用手机微信验证；模拟器联网成功不等于体验版或正式版均可用。

域名列表依据当前代码，不代表开发者必然能为任意 AppID 配置或发布相同能力。实际发布须满足微信后台要求；不要通过关闭证书校验或使用明文代理处理登录凭据。

## 首次使用

由使用者本人在登录页输入学校账号和密码，需要时完成短信验证。登录后同步课表；使用电量页面时分别选择照明和空调电表，不预设宿舍编号。

学校会话策略可能影响官方 App 的登录状态；避免反复尝试错误密码。小程序无法保证令牌永久有效，过期需重新登录。

## 测试

当前测试使用 Node.js、TypeScript 编译器和模拟的 wx 环境，不会用测试账号登录真实学校服务。

安装开发依赖后运行 `npm test`，也可显式指定编译器：

```sh
node tests/run.cjs /absolute/path/to/typescript/lib/typescript.js
```

脚本默认使用项目开发依赖中的 TypeScript，显式路径参数用于指定其他本机编译器。现有检查包括认证加密互通、MFA、会话清理、课表和缓存边界、电表响应与异常数据处理；不能替代学校真实接口和手机真机测试。
