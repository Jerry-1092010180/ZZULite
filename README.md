# ZZULite · 郑大轻享

轻量的郑州大学校园查询微信小程序，使用原生 TypeScript、WXML 和 WXSS 开发。

面向日常查看课表、成绩、校园卡余额和宿舍电量等需求。项目为非官方工具，与学校及「豫见郑大」官方 App 无隶属关系，不替代官方信息与业务办理渠道。

> 当前为开发中的源码快照，功能尚未完善，欢迎试用和贡献。以下功能描述依据 2026-11-07 的代码及已有验证记录，不代表所有功能已在微信真机环境验收或已上线。

首页、登录页及更多提供 [公开演示](docs/公开演示与提审说明.md)。演示使用标注的虚构数据，真实查询需要学校账号。

界面使用原生导航与底部安全区域，已有多种手机尺寸模拟检查；这不代替 iOS、安卓和鸿蒙微信真机测试。小程序显示名称与部分旧文案还需统一为「郑大轻享」。

## 技术与数据流

- 原生微信小程序，TypeScript + WXML + WXSS。
- 小程序直接连接学校 HTTPS 服务，不使用项目自建中转服务或微信云开发。
- 学校密码不持久化；有效令牌使用微信加密存储，不支持该能力时仅保留当前会话。
- 课表、电表选择与有限的最近读数在使用者本机保存；成绩仅在页面内存展示。
- 本小程序不依赖个人树莓派、ESP32 或私人电表采集服务，也没有连接这些设备的历史数据库。

## 快速开始

```sh
git clone https://github.com/Jerry-1092010180/ZZULite.git
cd ZZULite
npm install
npm test
```

使用微信开发者工具导入项目目录，填写自己的 AppID 并配置学校 request 合法域名。仓库使用测试占位 AppID；体验版和正式版需要开发者自己的账号及有效配置，详见开发说明。

## 开发版充值调试

开发版包含学校订单提交、只读查单、同笔收银台链接恢复和收银台预览。新增学校电费入口链接获取与复制。查单同时核对学校一卡通和收银台返回的状态、金额及订单信息。创建订单会请求学校接口，进入收银台后的付款与到账需以学校确认结果为准。体验版和正式版隐藏充值测试入口。

## 当前不包含

研究生教务、消费流水、充值或转账、图书馆预约、官方业务提交、云端同步及常驻后台采集。专注模块已移除。现有小程序最近读数缓存不等同于全天连续采集或完整的小时／天／周／月历史曲线。
